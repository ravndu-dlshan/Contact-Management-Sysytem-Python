# Contact-Management-Sysytem-Python
A simple Python command-line tool for managing contacts efficiently. Users can add, delete, search, and display personal contacts (name, age, and email).
  Features:

      Add Contact: Add a new contact with name, age, and email.
      Delete Contact: Select a contact to delete, with error handling for invalid inputs.
      Search Contact: Search by name, case-insensitive.
      Display Contacts: List contacts with an index for easy selection.
Usage:

  Run the script using Python (python contact_manager.py).
Commands available:
    'Add': Add a new contact.
    'Delete': Remove a contact.
    'Search': Find a contact.
    'Q': Quit the program.
